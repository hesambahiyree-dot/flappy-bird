# بالن غروب

بازی دوبعدی موبایلی با HTML5 Canvas و Capacitor Android.

## مکانیک
- بالن روی محور X ثابت است و خودش سقوط نمی‌کند.
- فقط یک جفت ستون با یک گپ وجود دارد.
- لمس خود ستون: هر لمس گپ را یک گام نرم به بالا می‌برد؛ در سقف جهت عوض می‌شود و لمس‌های بعدی گپ را پایین می‌آورند.
- کشیدن خود ستون: گپ دقیقاً به اندازه حرکت انگشت جابه‌جا می‌شود.
- لمس جای دیگری از صفحه ستون را تغییر نمی‌دهد.
- برخورد بالن با بدنه ستون = باخت.
- سرعت از همان شروع بالا است و تا امتیاز ۱۰ تدریجی سخت‌تر می‌شود؛ از ۱۰ به بعد سرعت و سختی جهش محسوسی دارد.

## Build
GitHub Actions با Capacitor پروژه Android را ساخته و APK قابل نصب `app-debug.apk` را به‌عنوان Artifact منتشر می‌کند.
