# Flappy Bird

یک بازی پروازی سبک و مستقل برای Android، با گرافیک اختصاصی و بدون استفاده از دارایی‌های اصلی Flappy Bird.

## اجرا

پروژه با Android Gradle Plugin ساخته می‌شود و به Android SDK 35 نیاز دارد.

## کنترل

- لمس صفحه: پرش
- برخورد با لوله یا زمین: پایان بازی
- رکورد بهترین امتیاز روی دستگاه ذخیره می‌شود.

## ساخت APK

GitHub Actions به‌صورت خودکار APK نسخه Release را می‌سازد و به‌عنوان Artifact در اختیار شما می‌گذارد.
