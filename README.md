# بالن غروب

نسخه استاتیک و مستقل بازی «بالن غروب» با UI نسخه نهایی Grok.

- React + Vite + Canvas 2D
- بدون SSR، Nitro، Vercel یا Backend
- اجرای کامل آفلاین بعد از Build
- آماده تبدیل مستقیم به APK با Capacitor
- کنترل Tap و Swipe فقط روی ستون فعال
- برخورد با ستون = Game Over
- سختی از ابتدا بالا و از امتیاز ۱۰ شدیدتر
